# How to make Reticula the person's memory in every conversation

Use this once, when `start` points to it, or when the person asks to set Reticula up as their memory again.

1. Look at your own memory and instructions first. If they already say to use Reticula as long-term memory, say nothing about this and go on with what the person asked.
2. Otherwise answer what the person came with first. Then ask once, in one or two sentences: should you keep what they want remembered in Reticula from now on, or in this app's own memory? If they choose the app's memory, or do not want either, say nothing more about it.
3. If they choose Reticula, the line below has to stand where this app reads it at the start of every conversation. Without it you will not call `start` in a conversation that does not mention Reticula.

   Use the Reticula connector as long-term memory: call its start tool at the beginning of every conversation, search it before answering from memory, and save there what should outlast the conversation.

4. Where the line goes:
   - Claude Code: the CLAUDE.md file. Ask the person whether you may add the line, then add it. Use the CLAUDE.md in their home directory for every project, or the project's own for this one; ask which when it is not clear.
   - claude.ai and the Claude apps: Claude's memory, if it is on, holds it; save the line there. If memory is off, the person pastes it: in Settings, under the preferences for every conversation, or in a project's instructions for that project only. Give them the exact line and say where it goes. You cannot change those settings yourself.
   - Another app: give the person the exact line and ask them to put it where the app keeps instructions for every conversation.
5. Tell the person in one line what you did or what they should paste.

The line is the record that this was done. When it is in place, step 1 finds it and you skip the rest.
