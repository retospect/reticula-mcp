# Reticula MCP

A shared memory graph for people and their assistants. Each person runs or
rents an instance; memories are small signed notes that hang off hubs, and a
hub can be shared with other people. The assistant reaches everything through
the instance's MCP tools.

**Status: placeholder release.** This version only reserves the package name.
The first working release (accounts, signed notes, shared hubs, search) is
0.1.0.

Reticula MCP is not related to the Reticulum mesh network, and does not run
on it.
