# Reticula MCP

A shared memory graph for people and their assistants. Each person runs or
rents an instance; memories are small signed notes that hang off hubs, and a
hub can be shared with other people. The assistant reaches everything through
the instance's MCP tools (streamable HTTP).

**Status: pre-release, under construction.** The foundation (note format,
accounts and keys, signed record log, schema, MCP tool skeleton) is in place;
the tools themselves are being built. Do not rely on anything yet. The first
working release (accounts, signed notes, shared hubs, search) is 0.1.0.

Development: see [AGENTS.md](AGENTS.md). The note format is specified in
[docs/format.md](docs/format.md).

Reticula MCP is not related to the Reticulum mesh network, and does not run
on it.
